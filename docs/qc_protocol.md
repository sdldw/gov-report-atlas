# 质量控制协议

## 抽检一：正文抽取（100 份）

- 分层抽样：中央 5、省级 25、市级 70；
- 每份核对三件事：标题对不对、正文有没有混进导航/版权、字数是否在合理区间；
- 判定：**可用 / 部分可用 / 失效**；
- 通过线：可用率 ≥ 85%，否则回国改解析器。

## 抽检二：概念命中（50 份）

- 每份随机取 10 条命中句，人工判断是否真的在谈这个概念；
- 计算精确率，通过线 ≥ 0.9；
- 低于通过线说明词典太宽，回退变体表。

## 抽检三：复制率（30 对）

- 人工从中央文本与地方文本各取 15 句，判断是否为同义复制；
- 与 SimHash 判定做交叉表，报告准确率与误判类型。

## 记录格式

每次抽检输出一个 CSV：`doc_id, checker, verdict, note, ts`。
抽检人**不看**该地区的经济数据与是否被表扬/批评，避免预期污染判断。
