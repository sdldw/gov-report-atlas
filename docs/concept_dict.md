# 概念词典说明 v0.1

## 为什么需要它

「政策注意力」不能直接观测。做法是选定一组概念，用它们在文本中的**份额**作为代理。
词典是这支温度计的水银柱——词典错了，后面全错。

## 三条规则

1. **变体合并**：同一概念的异体写法（`人工智能+` / `人工智能＋` / `AI+`）合并计数，
   否则全角半角会制造假差异。
2. **份额而非次数**：分母是**汉字总数**。市级报告 8,000 字、省级 20,000 字，
   直接比次数等于比篇幅。
3. **可追溯**：每个词条记录 `origin`（中央首次提出的时间），先导性靠它计算。

## 必做的敏感性分析

报告里至少要给出两组对照：

- **窄词典** vs **宽词典**（只留核心词 / 加入所有变体）；
- **去掉高频泛词**（如「高质量发展」这类几乎每篇都有的词）。

如果结论在两套词典下方向一致，才能写"稳健"。

## 扩词流程

1. 种子词人工确定（当前 8 个，均在 `config/concepts.yaml`）；
2. 用词向量找近邻，人工筛掉语义漂移的候选；
3. 任何新增词条都要在 `changelog.md` 留一行记录。
